## 1. 档位

### 1.1 数据字段

底层已验证：

- `0x21410320[19]`：`1..6=M1..M6`，`7=P`，`8=R`，`9=N`，`10=D`
- `0x2141342A[1]`：`0=P,1=R,2=N,3=D,7=手动`
- `0x11400400`：bitmask `4=P,8=D,2=R,1=N`

建议主题统一为：

```text
gear       1=P, 2=R, 3=N, 4=D, 5=M1, 6=M2, 7=M3, 8=M4, 9=M5, 10=M6, 11=M7
gearRaw    原始码（0x21410320[19]）
gearText   "P"/"R"/"N"/"D"/"M1"..."M6"
```

用户在自己主题里按 `gear` 数值写条件，例如：

```json
{ "source": "gear", "op": "eq", "value": 1 }  // P
{ "source": "gear", "op": "eq", "value": 5 }  // M1
```

不对“1/2/3 档是否存在”做假设：读到什么就暴露什么，用户自行决定是否可用。

### 1.2 数据链路

DiPlay 已有 `LampReaderService` 在 `com.wt.n2048`，该进程可访问 `CarPropertyManager`：

1. `ILampReader.aidl` 增加 `getGearCode()` / `getGearSelection()` / `getGearText()`。
2. `CarLampSource` 增加：
   - 优先 `getIntArrayProperty(0x21410320, 0)[19]`
   - 回退 `getIntArrayProperty(0x2141342A, 0)[1]`
   - 再回退 `getIntProperty(0x11400400, 0)` bitmask
3. `LampReaderService` 实现 AIDL。
4. `CarDataMonitor.State` 增加 `gearCode`，150ms 轮询。
5. `ThemeData` 增加 `gear/gearRaw/gearText`。
6. `CustomThemeHost.data()` 填入。

### 1.3 主题操作

- `visibleIf` / rules / states：`gear` 数值条件。
- 文本：`{gearText}`、`{gear}`、`{gearRaw}`。
- bind：`source: "gear"`，做颜色/缩放/位移映射。
- 关键帧：照常叠加，不依赖数据。
- WPF：预览工具条增加 P/R/N/D/M1..M6 下拉；规则/状态源列表加 `gear`。
- 旧版 App 忽略新源，主题仍可显示基础外观。

## 2. 转向灯

### 2.1 数据字段

| 属性 | 含义 | 用法 |
|---|---|---|
| `0x21400A36 == 2` | 左拨杆请求 | 稳定状态 |
| `0x21400A38 == 2` | 右拨杆请求 | 稳定状态 |
| `0x2940341B == 1` | 双闪请求 | 独立 |
| `0x21400A35 == 1` | 左灯实际输出 | 闪烁镜像 |
| `0x21400A37 == 1` | 右灯实际输出 | 闪烁镜像 |

注意：A36/A38 静息值是 1，不是 0；双闪不会改 A36/A38；要闪灯镜像必须轮询输出，采样 ≤100ms。

### 2.2 主题字段

```text
turnLeft       0/1  左拨杆请求
turnRight      0/1  右拨杆请求
hazard         0/1  双闪请求
turnLeftBlink  0/1  左灯实际输出
turnRightBlink 0/1  右灯实际输出
```

文本/条件用 `eq 1`；bind 用 0/1 映射；状态可做“左转/右转/双闪”视觉布局；规则可做“打灯时提示/闪动”。

### 2.3 数据链路

同样复用 `LampReaderService`：

- AIDL 增加 5 个方法；
- `CarLampSource` 增加对应 `getIntProperty`；
- `CarDataMonitor` 对转向灯用 100ms tick；
- `ThemeData` / Host 填入；
- WPF 预览增加左/右/双闪三个开关。

## 3. PCM / 音频

已有 `MusicReactiveBus`：

- `level` 0..1
- `bass` 0..1
- `beatCount` / `pulseAt`

建议 `ThemeData` 增加：

```text
audioLevel 0..1
audioBass  0..1
beatPulse  0..1（每次重音衰减）
```

规则/状态/绑定/文本都可使用；频谱另做层。

## 4. 专辑封面

现有 `ClusterSongView.setArtwork(Bitmap)` 已拿到 CarPlay 封面，但自定义主题没有入口。

建议新增 live 槽位：

```json
{ "type": "live", "slot": "cover", "z": 0, "dst": [0,0,1920,720] }
```

- `LampReader` 不参与；封面在主进程媒体回调里已有；
- `CustomThemeHost` 新增 `CoverView`/ImageView，填入当前 artwork；
- 规则/状态/关键帧可对 cover 层做 alpha/scale/x/y/visible；
- 不支持对 cover 做 setImage（或 setImage 切换为静态图，明确语义）。

## 5. 频谱层

新增 layer 类型：

```json
{
  "type": "spectrum",
  "z": 5,
  "dst": [0, 0, 1920, 200],
  "bands": 16,
  "color": "#FF00E5FF",
  "gap": 4,
  "direction": "up",
  "smoothing": 0.6
}
```

- 在 `MusicReactiveBus` 对同一份音乐 PCM 做 16/24 段 FFT（不做整段缓存）；
- 仅音乐通道，导航/通话不参与；
- 规则/状态/关键帧可控制 spectrum 的可见、alpha、颜色、位置；
- bind 可选 `source: "audioBass"` 控制颜色；
- WPF 预览用模拟数据（正弦+随机）驱动，不依赖真 PCM。

## 6. GIF

当前 Android `BitmapFactory`、WPF `BitmapImage` 都只取首帧。

建议：

- `image` 层 `.gif`：
  - Android API 28 优先 `ImageDecoder`/`AnimatedImageDrawable`，minSdk 25 回退 `Movie`；
  - WPF `GifBitmapDecoder` + PreviewControl Tick；
  - schema 增加可选 `loop` / `speed`；
- 规则 `setImage` 支持切成 GIF；
- 状态覆盖 alpha/scale/x/y/dst 仍有效；
- 全屏 GIF 限制 1920×720、帧数/内存预算；建议只用于小图标，或改用 PNG 序列帧。

## 9. 三指策略（已改）

- 手动三指 `activationRequested` 不再被 `autoFlyEnabled` 拦截；
- 通道已开：只清请求，不再发完整序列；
- 通道未开：只调 `InCallClusterBridge.reassertProjection()`（F0+C0+Z，静默）；
- `openState=false` 时 reassert 会 no-op；按“只静默”策略接受不恢复；
- 自动飞屏的完整序列路径不变。
