# 火焰双擎：自定义主题复刻评估

日期：2026-11-13
对照：`PortholeDualRingView.kt`（内置原生主题）与 `CUSTOM_THEMES.md`（自定义主题规范）

## 结论

**不能 1:1 复刻。**

现有自定义主题可以做“静态近似”：双环、深色背景、底部火墙轮廓、循环火星、文字；但内置火焰双擎的核心是**程序化火焰/粒子 + 发光 + 分段弧/彗星 + 程序化纹理**，这些不在当前 schema 里。

**补充（2026-11-13）**：火墙可以用 `vector` + `bind` 的展开填充做，双环也可以用 `gauge` 的矢量圆弧做；已按这个思路做了 `flame_dual_ring_v3`，观感比 v1 接近很多。仍缺的是每帧火焰舌/火星/发光/分段彗星，不是“完全画不出来”。

近似示例：

- 主题：`custom-theme-test/flame_dual_ring_v3/theme.json`
- 预览：`DiPlayThemeMakerWpf/docs/flame-dual-ring-v3.png`
- WPF smoke：通过；但与内置观感仍有差距。

## 已能覆盖

| 元素 | 现有能力 |
|---|---|
| 深色/径向背景 | `brush` radial/linear |
| 左右双环 | `gauge`（speed/rpm、start/sweep、ticks、labels、colors） |
| 底部暖光 | `brush` radial |
| 火墙大轮廓 | `vector` polygon + `bind` 按 speed 向上填充 |
| 静态火星 | `shape` ellipse + `animations` y/alpha |
| 文字 | `text` + bind |
| 规则/状态/关键帧 | 已有 |

## 缺失（按重要性）

### P0：没有程序化火焰/粒子

内置：

- 40 个火焰舌，三层宽度/缩放/相位随机；
- 140 个火星，速度决定数量/上升速度；
- 每帧 `sin/cos` 噪声、`cubicTo` 贝塞尔轮廓、速度驱动火墙高度 `150 + 600*(speed/220)^0.55`；
- 阴影/多层叠加。

自定义主题只有静态 `vector` polygon 和固定关键帧，无法表达随机火焰舌、速度驱动粒子、有机曲线。

**需要新增：**

```json
{
  "type": "flame",
  "dst": [0, 0, 1920, 720],
  "speed": [0, 220],
  "height": [150, 700],
  "colors": ["#FF2D08", "#FF7018", "#FFB43C"],
  "emberCount": 140,
  "layerCount": 3,
  "blend": "screen"
}
```

或通用 `particles` 发射器 + `path` 贝塞尔轮廓；`flame` 是更省事的专用层。

### P0：gauge 缺“发光/彗星/分段外弧/红区”

内置：

- 外圈 72 段分段弧，按比例点亮；
- 彗星头拖尾（comet）；
- 双层描边 + `setShadowLayer` 发光；
- 转速 4500 以上红区；
- 圆形暗色底板。

现有 `gauge` 只有单弧、track、ticks、labels、colors，没有：

- `segments` / `segmentGap` / `segmentWidth`
- `comet`（头半径/拖尾长度/颜色）
- `glow`（半径/颜色/强度）
- `redline`（阈值/颜色）
- `plate`（半径/颜色/边框）
- `needle`

**需要扩展 `gauge`：**

```json
"gauge": {
  "data": "speed",
  "segments": 72,
  "segmentGap": 2,
  "comet": { "head": 5, "tail": 26, "color": "#FFFFD166" },
  "glow": { "radius": 12, "color": "#B0FF9123" },
  "plate": { "radius": 151, "color": "#D9020508" }
}
```

### P1：shape 缺圆角/发光/混合模式

- 内置仪表底板是圆角矩形/圆形+边框；
- 现有 `shape` 只有 `rect` / `ellipse`，没有 `cornerRadius`，也没有 `glow`/`shadow`/`blend`。

需要：

```json
{ "type": "shape", "shape": "roundRect", "cornerRadius": 18, "glow": {...}, "blend": "screen" }
```

### P1：没有 `path`（贝塞尔/裂纹/有机轮廓）

`CUSTOM_THEMES.md` 明确 `path` 未支持；内置背景裂纹、火焰舌是曲线路径。

需要：

```json
{ "type": "path", "d": "M... C... Z", "fillRule": "nonzero", ... }
```

或至少 `vector` 支持 `curves` / 控制点。

### P1：程序化炭纤维/六边形/裂纹背景

内置 `ensureBackdrop()` 生成纹理；自定义主题只能用静态图片 `image` 或渐变。

需要：

- `pattern` 图层（carbon/hex/crack，参数化），或
- 官方提供一张背景 PNG，主题引用；如果接受“素材化”，这是最快路径。

### P1：bind/关键帧缺高级驱动

内置：

- `shownSpeed` 低通 `current + delta*0.18`；
- 火焰高度用幂函数 `^0.55`；
- 粒子速度随车速变化。

现有 `bind.ease` 只是毫秒低通，`animations` 是固定时间轴；没有：

- `bind.property = height/dst/glow/particleRate`
- `ease: power/curve`
- 数据驱动动画速度。

### P2：字体/描边/多色渐变

内置 plate/环颜色和字体固定；现有 text 只有字号/颜色，无字体、描边、发光。要完全一致还需要 `fontFamily`/`stroke`/`glow`。

## 建议实施顺序

1. **flame 层**（或 particles + path）：解决核心观感，1–2 天。
2. **gauge 扩展**：segments/comet/glow/redline/plate，1–2 天。
3. **shape roundRect + glow + blend**：0.5–1 天。
4. **pattern 背景**：0.5–1 天，或先用官方 PNG。
5. **path 层**：1–2 天，补裂纹/有机轮廓。
6. **bind 高级属性**：1 天。

全部补齐后可以做到接近内置，但仍不建议追求逐像素一致；**原生主题应保留为“极致性能/观感”版本，自定义主题做可编辑近似**。

## 兼容性

- 新层/新字段只影响新主题；旧版 App 遇到未知类型会跳过，不会崩溃。
- 火焰/粒子层需要 30fps 预算，全屏时建议限制粒子数/层数。
- 旧主题不受影响。
